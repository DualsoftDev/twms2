file_uploadDEXA 데이터 가져오기

DEXA.sqlite3 파일을 첨부하면 자산의 aug 정보(Station·벤더·사양·라인)와 PLC/Servo 연결정보(IP·경유IP·Base·Slot)를 분석합니다. 가져오기를 눌러도 바로 저장되지 않으며, 아래 'aug 데이터 이전하기'에서 적용을 눌러야 DB에 반영됩니다.

선택된 파일 없음

sync_altaug 데이터 이전하기

아래 내용이 TWM2 DB에 반영됩니다. 적용을 눌러야 실제로 저장됩니다. 기존 자산의 확장·연결정보는 덮어쓰며, 라인·그룹은 전체 교체됩니다.

map배치 가져오기

TWM1 라인을 TWM2 레이아웃(도면)에 매핑하면 자산 위치와 그룹이 자동 배치됩니다. 같은 도면 이미지를 사용해야 좌표가 정확히 맞습니다.
