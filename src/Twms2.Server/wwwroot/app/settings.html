※ 업로드한 이미지는 기본 마크와 동일한 위치·크기(46×46 박스)에 비율을 유지한 채 맞춰 표시됩니다.
※ PNG·JPG 는 업로드 시 SVG 로 자동 변환되어 저장됩니다. 삭제하면 기본 TWMS 마크로 복원됩니다.
