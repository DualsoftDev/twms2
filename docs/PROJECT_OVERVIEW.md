# TWM 2.0 (Tool & Workspace Manager)

## 개요

TWM 2.0은 산업용 자산(PLC, HMI, 드라이브, 서보 등)의 백업/버전 관리 서버인 **DEXA**를 위한 웹 기반 관리 프론트엔드입니다. 기존 DEXA 서버 인프라에 현대적인 웹 UI를 제공하여, 자산 관리, 스케줄링, 이력 조회, 사용자 관리 등의 기능을 브라우저에서 수행할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| **대시보드** | DEXA 서버 연결 상태 모니터링 |
| **자산 관리** | 트리 구조로 자산 탐색, 상세 정보 조회/편집, 일괄 편집 |
| **자산 테이블 편집** | 테이블 형태로 여러 자산을 한번에 편집 |
| **스케줄 관리** | Cron 기반 트리거 조회, 실행, 추가/삭제 |
| **이력 조회** | 백업 작업 로그 및 성공/실패 이력 확인 |
| **사용자 관리** | 로그인 인증, 권한 관리 (관리자 전용) |
| **서버/DB 설정** | 서버 구성 및 데이터베이스 관리 (관리자 전용) |

## 기술 스택

| 구분 | 기술 |
|------|------|
| **프론트엔드** | Blazor Server + MudBlazor (Material Design UI) |
| **백엔드 (웹)** | C# / ASP.NET Core (.NET 10) |
| **백엔드 (코어)** | F# / Akka.NET (액터 모델 기반 분산 통신) |
| **데이터베이스** | SQLite (DEXA DB: 읽기 전용, TWM DB: 로컬 메타데이터) |
| **ORM** | Dapper (경량 ORM) |

## 프로젝트 구조

```
src/
├── DexaWeb.Server/          # C# Blazor 서버 앱
│   ├── Components/
│   │   ├── Layout/          # 레이아웃 (MainLayout, NavMenu)
│   │   ├── Pages/           # 페이지 컴포넌트
│   │   │   ├── Assets/      # 자산 관리 (탐색기, 테이블 편집, 일괄 편집)
│   │   │   ├── Admin/       # 관리자 기능 (사용자, 설정, DB)
│   │   │   └── ...          # 대시보드, 스케줄, 이력 등
│   │   └── Shared/          # 공유 컴포넌트 (AssetTreeView 등)
│   ├── Services/            # 비즈니스 로직 서비스
│   ├── Models/              # 데이터 모델
│   └── Data/                # DB 연결 및 초기화
│
└── DexaWeb.Dexa/            # F# 클래스 라이브러리
    ├── Models/              # 도메인 모델 (Asset, User, Trigger 등)
    ├── Messages/            # Akka 메시지 타입 (요청/응답)
    └── Infrastructure/      # Akka 액터 시스템, 직렬화, 클라이언트
```

## 아키텍처

```
┌─────────────────────────────────┐
│   Blazor UI (MudBlazor)         │  브라우저
└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐
│   C# 서비스 레이어               │  DexaWeb.Server
│   (Asset, Schedule, User, ...)  │
└───────┬───────────────┬─────────┘
        │               │
   ┌────▼────┐   ┌──────▼──────┐
   │ Dapper  │   │ Akka.Remote │   DexaWeb.Dexa (F#)
   │ (읽기)  │   │ (쓰기/명령) │
   └────┬────┘   └──────┬──────┘
        │               │
   ┌────▼────┐   ┌──────▼──────┐
   │ DEXA DB │   │ DEXA Server │   외부 시스템
   │ SQLite  │   │ (TCP/IP)    │
   └─────────┘   └─────────────┘
```

- **읽기 경로**: Dapper를 통해 DEXA SQLite DB에서 직접 조회 (빠른 응답)
- **쓰기 경로**: Akka.NET 원격 액터를 통해 DEXA 서버에 명령 전송 (안정적 전달)
- **로컬 저장소**: TWM 전용 SQLite DB에 메모, 감사 로그 등 부가 데이터 저장

## 설정

`appsettings.json`에서 다음 항목을 구성합니다:

- **DexaServer**: DEXA 서버 IP/포트, 타임아웃 설정
- **DexaDb**: DEXA SQLite 데이터베이스 경로
- **TwmDb**: TWM 로컬 데이터베이스 경로
- **Kestrel**: 웹 서버 리스닝 주소 (기본 `http://0.0.0.0:5000`)
